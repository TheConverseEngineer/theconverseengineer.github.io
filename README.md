# Vraj Parikh's portfolio

A minimal, content-led developer portfolio focused on machine learning, autonomy, and high-performance systems.

Read [the project brief](docs/PROJECT_BRIEF.md) before making product or design changes. Agent-specific implementation guidance lives in [AGENTS.md](AGENTS.md).

## Development

Install dependencies, then start the development server:

```bash
pnpm dev
```

Open [http://localhost:3000](http://localhost:3000).

Useful checks:

```bash
pnpm lint
pnpm build
```

## Stack

- Next.js 16 App Router
- React 19
- TypeScript
- Tailwind CSS 4
- pnpm

This project uses the version-matched Next.js documentation bundled in `node_modules/next/dist/docs/` as its framework reference.
